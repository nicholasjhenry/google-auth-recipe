# Google Auth Recipe

A reference Phoenix application demonstrating how to implement Google OAuth authentication.

See the [Google Auth Setup](guides/google-auth-setup.md) guide for creating a Google Cloud project and configuring the OAuth Consent Screen.

## Getting Started

  * Run `docker compose up -d` and `mix setup` to install and setup dependencies
  * Start Phoenix endpoint with `mix phx.server` or inside IEx with `iex -S mix phx.server`
  * Visit [`localhost:4000`](http://localhost:4000) from your browser
